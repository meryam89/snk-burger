# 🍔 SNK Burger

SNK Burger est une application web de commande de repas développée avec Django.

## Fonctionnalités

- Inscription et connexion des utilisateurs
- Consultation du menu par catégories
- Ajout de produits au panier
- Modification des quantités et suppression de produits
- Validation des commandes
- Historique des commandes
- Suivi du statut des commandes
- Interface d'administration Django
- Gestion des stocks
- Sécurisation de l'accès aux commandes

## Technologies utilisées

- Python
- Django
- SQLite
- HTML
- CSS
- Git et GitHub
